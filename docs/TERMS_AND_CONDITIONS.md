## 2. Description of Services

Awaken is a gamified alarm and fitness application designed to help users establish consistent morning routines and physical exercise habits. Key features include:
* **Camera-Verified Alarms:** Alarms that require real-time physical exercise (e.g., squats, push-ups) verified via on-device pose detection to be dismissed.
* **Geospatial Territory Capture:** GPS-tracked outdoor running sessions that capture geographic areas ("territories") on a shared map upon completing a closed loop.
* **Squads & Community:** Leaderboards and social features displaying exercise stats, active runs, and conquered territories.
